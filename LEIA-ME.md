# Site Nadhy Estética

Site estático (HTML/CSS/JS), sem backend.

## Estrutura
- `index.html` — página única
- `css/style.css` — cores no topo (`:root`)
- `js/main.js` — WhatsApp e mensagem padrão no topo do arquivo
- `img/` — fotos

## Trocar as fotos
Coloque arquivos `.jpg` na pasta `img/` com estes nomes (até lá aparece um degradê):
`hero.jpg`, `massoterapia.jpg`, `rejuvenescimento.jpg`, `depilacao.jpg`, `tratamentos.jpg`, `pele.jpg`, `bem-estar.jpg`, `galeria-1.jpg` a `galeria-6.jpg`.
Use fotos reais da clínica ou imagens com licença de uso; prefira até ~300 KB cada.

## Publicar
- **Hospedagem compartilhada (ex.: Hostinger):** envie todo o conteúdo da pasta para `public_html`.
- **GitHub Pages:** suba os arquivos em um repositório → Settings → Pages → branch `main`, pasta `/ (root)`.
- **Vercel:** importe o repositório (ou arraste a pasta); sem configuração de build.
